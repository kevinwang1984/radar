03 VISTA：把原始画面存在上下文之外，让模型按需回看 多模态 Agent 的视觉档案：存原图，用时再调回。 中文 1 小时 cn:qbitai ›
是什么MIT 的 **VISTA**（论文《VISTA: A Visual Harness for Reasoning in an Interactive World》，共同一作 Qiushi Han、胡珂雅、Linlu Qiu，另有 Cathy Wu 与**何恺明**），一句话是「不动模型的权重，改模型获取、保存、使用视觉信息的方式」。它针对的是现有 Harness 的短板：**光有文字记忆不够** —— 模型第一次看一张图时，未必知道哪个细节后面会重要；而交互历史一长，早期画面会被移出上下文或被文字摘要替代。三个组件：**视觉观测**（ARC-AGI-3 里把官方 64×64 画面放大成 512×512 PNG，保留颜色、外观与空间关系）；**无损视觉记忆**（每次动作后把环境返回的所有画面原样存到**上下文之外**，**包括动作过程中的动画中间帧**，按回合号 + 帧号建索引 —— 所以模型不必提前判断什么值得记）；**主动视觉检查**（`inspect` 工具：指定某个历史回合调出画面、裁剪放大局部、一次调多帧对比动作前后）。执行流程是「观察 → 假设 → 必要时回看取证 → **先预测这次操作会带来什么变化** → 执行 → 拿实际结果与预测对比 → 修正对规则的理解」。上下文里默认只放最后一帧，中间帧全留在档案里等调取；另外两份文字笔记 `GUIDE.md`（跨关卡可复用的规则）与 `WORKING.md`（当前关卡状态与计划）负责接续上下文。**实测数字**：ARC-AGI-3 全部 25 款公开游戏，**Claude Opus 5.0 拿到 RHAE 满分 100、游戏动作数比首次游玩的人类基线少 57.4%**，`GPT-5.6 Sol` 同样全部通关、得分 **99**；同模型对照官方基础框架，GameWorld 170 项任务成功率 **40.0% → 63.3%**，AI GameStore 10 个游戏综合得分 **47.3 → 140.3**（人类中位数归一为 100），BabyVision 39 道迷宫与连线题准确率 **41.0% → 63.2%**（这组只有静态图片，靠放大与查像素也能改善）。**【原站核验】** `www.qbitai.com` 可达、全文已读。**未能核验**：论文原文（`arxiv.org` 今天解析到非公网地址、打不开），**上述数字全部是量子位的转述口径**。 为什么值得你花时间① 你正在做画布 / 分镜这类**视觉工作流**，这条给的是一个可以直接照搬的结构：**把大块视觉证据留在上下文之外，只把「当前需要的那几帧」调回来**。这和你熟悉的「上下文预算」是两种思路 —— 不是把图压小或摘要掉，而是**承认原始帧是证据、摘要只是当前理解，两者分开存**，需要时再取证。② 三个能立刻搬走的动作：**保存中间帧**（不只存每一轮的终态，动画中间帧往往是判断「发生了什么」的唯一证据）；**让模型先预测再执行、用实际结果对预测做校验**（这比只给成功/失败反馈信息量大得多）；**配两份 Markdown 笔记分层**（一份跨任务的规则、一份当前任务的状态）。③ 它和下面一条（Memento 3）构成今天最好的对照：**同一个基准、几乎同一批模型、同样接近满分，但一个主张「存原始画面按需回看」、一个主张「把规则写成可执行代码来推演」** —— 值得你把这两条摆在一起读一遍，再决定你的 Agent 该往哪边靠。**注意**：三条评测都是**论文方自报**，且都用了「配自家 Harness vs 配官方基础框架」的对照，换 Harness 的收益里有多少能迁到你的场景仍要自己试。 上手成本1 小时（读它的三个组件与执行流程；论文原文打不开，只能读量子位的转述） 入口https://www.qbitai.com/2026/10/502628.html （论文 PDF https://arxiv.org/pdf/2610.02200 ，今日不可达） 读详情（翻译 + 要点）→
04 Memento 3：给自己写攻略、把规则写成可执行代码 Agent 边玩边写规则手册，再拿自建模拟器推演。 中文 1 小时 cn:qbitai ›
是什么华为诺亚方舟实验室联合 UCL 等团队的 **Memento 3**，方法名 **Model-Based Recursive Self-Improvement**，核心叫 **Code as Model（代码即模型）**。它不训模型、不动权重（底模是 **Claude Opus 5**，开 Extra-High 推理强度），而是让 Agent 在交互中自己维护两样东西：**Rulebook**（一份 Markdown 规则手册，记录「什么操作触发什么效果、怎样通关、还有哪些规则没搞明白」）与 **Executable World Model**（把总结出的规则**直接写成能跑的 Python 代码**，等于自己搓一个简化版游戏模拟器），有了这两样就能先在自己搭的模拟器里推演路线再决定下一步。关键是**写错了会自己推翻重来**：论文里的例子是它起初以为踩上特殊地板会让角色携带的图案按进入方向镜像翻转，实测后发现是**顺时针旋转 90 度、与进入方向无关**，于是改手册、同步改代码；改完还要**重新模拟此前的操作、逐格对比 64×64 画面**确认能复现真实结果，对不上就继续改。研究团队甚至**引入了 Git 版本管理**，每次修改规则与代码都留记录、可回滚 —— 符号解密游戏 `tr87` 的同一份手册迭代了 **11 个版本**。**实测数字**：ARC-AGI-3 公开集 **25 款游戏、183 个关卡全部通关**，**RHAE 满分 100**，总操作 **7518 次**（人类完成同一套需 17135 次，**少约 56%**；此前最强的独立基线 baseline1 是 8347 次）；对照面，同一底模在 ARC Prize 官方标准框架下平均 RHAE 只有约 **40.7**，**换 Harness 提升 59.3 分**。消融：保留规则手册时共 617 次操作，去掉手册只留代码世界模型要 677 次（**手册省约 9% 操作**）；同时维护两套世界模型（共享操作记录、各自推演不同假设）在游戏 `wa30` 上把 899 次降到 **597 次（约 34%）**。Atari Pong 上更有意思：策略学成后**不再调用大模型**，三次不同开局全部 **21:0**；而每一步都让大模型看画面决策的对照只有 **-19** 分（随机约 -20.7）；学出这套策略大约只用了 **9500 帧**画面，传统强化学习常需数十万至数亿帧。**【原站核验】** `www.qbitai.com` 可达、全文已读。**未能核验**：论文原文（`arxiv.org` 打不开），数字全部是量子位的转述口径；**双世界模型那 34% 只在 `wa30` 一款游戏上验证，不能外推**；成本口径也没给（Extra-High 强度的 Opus 5 跑探索 + 生码 + 验证，token 与算力不便宜）。 为什么值得你花时间① 这是今天最接近「可抄的 Agent 架构」的一条，而且它的每一块都能落到你的 Gitea / wayfinder 流程上：**把 Agent 学到的规则写成可执行代码而不是散文**（可运行 = 可验证 = 可回归，改错了能靠对比复现来发现）、**规则用 Git 管版本**（你已经天天在用这套纪律，它只是把它用在了「Agent 的世界观」上）、**先预测再执行**（预测与实际不一致正是「知识该更新了」的信号，而不是一次失败）。② 它给出了「什么时候不该让大模型上场」的硬证据：Pong 上策略成熟后**不再调用模型就是 21:0，每步都调用反而是 -19 分** —— 对你做自动化流水线直接有用：**把已经稳定的部分固化成代码，模型只负责摸索与修正**，既省钱又更稳。③ 与正文 03 摆在一起读：VISTA 说「保留原始画面、按需回看」，Memento 3 说「把理解固化成可执行代码、自己造模拟器推演」—— 两条都不训模型、都在同一个基准上打满分，**区别在于把「理解」存在哪里**（存在原始证据里 vs 存在可执行的模型里）。你的画布 / 分镜 Agent 应该两边都借一点：**证据留原始素材，规则沉淀成能跑的代码**。 上手成本1 小时（读论文要点与消融数字；复现要自己写 Harness，属半天以上） 入口https://www.qbitai.com/2026/10/502654.html （论文 https://arxiv.org/abs/2610.11794 ，今日不可达） 读详情（翻译 + 要点）→
05 Open Academic Paper Gen：每个引用都回原文核对 写论文初稿，并逐条回原文核对引用真假。 中文 半天 cn:qbitai ›
