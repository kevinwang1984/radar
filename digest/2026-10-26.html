01 Omniroute：自托管的多模型路由网关 把多家模型收进一个自托管路由网关。 其他 15 分钟 weekly:skills-sitemap-diff ›

04 Agent 工具防护层：150 行代码的四道闸 给 Agent 工具调用加四层拦截的代码。 中文 1 小时 cn:juejin ›
是什么掘金 10-25 的实操文（作者郑恩赐）。它把 Agent 工具调用的防护收进一个 150 行的 Python 文件，只依赖标准库：L1 参数 schema（别名归一、必填、未定义字段拒绝、类型校验），L2 暴露收敛（`visible_tools()` 只把当前角色可见的工具下发给模型），L3 白名单 / 硬禁 / 权限等级，L4 高危确认 + 同指纹重复调用熔断。 为什么值得你花时间你的 Agent 一旦接上写文件、发消息、改数据库这类工具，最危险的不是模型答错，而是它“合法地”调了一个不该调的工具；这篇把四道闸写成可复制的代码，五个场景覆盖参数名幻觉、类型错误、硬禁、越权、重复调用。接进现有 runtime 只要守三个点：候选集用 `visible_tools()`、所有 `tool_call` 走 `guard.call()`、`pending_confirm` 落状态机并用指纹比对确认。边界：它拦不住业务逻辑错、用户明确要求的危险操作、提示注入；`call_counts` 是进程内字典，生产要换 Redis 带 TTL；只接两三个只读工具的话，留 30 行参数校验就够。 上手成本1 小时（复制代码跑 demo 15 分钟；接进现有 Agent 1 小时） 入口https://juejin.cn/post/7700194552505892891 读详情（翻译 + 要点）→
05 Skill 评测复盘：用 100 个 case 推翻“全员满分” 用大样本和脚本判分选模型的方法。 中文 15 分钟 cn:juejin ›
是什么掘金 10-25 的复盘（作者冬奇Lab）。起点是一份“高频 Skill 模型适配评估”：8 个任务场景各 1 个 case、每个跑 5 次、由 AI 判对错，结果头部四个模型准确率都在 97.5% 以上。作者认为这不是模型都强，而是题太简单 / 判分太松，于是只重做“获取 Jira bug 信息和附件”一个场景：100 个不同 case × 3 次采样，用脚本逐字对比 ground truth（标题、描述、附件数量 / 名称 / 大小），完全一致 5 分，否则 0 分。 为什么值得你花时间你正在给 wayfinder 选模型 / 技能，最容易犯的错就是拿一份“全员接近满分”的评测当结论；这篇的结果很反常识——sonnet-5-5 得分 4.93 最高，但 3 次错误都是致命的（拉错单号、流程卡住）；ds-v4.1-flash 4.78，错误多为个别字词转述（10 例）和未按格式输出（2 例），Token 只有约四分之一（45,995 vs 174,485），耗时 34.6s vs 44.4s。选型看“错误代价 × 频率 + 调用成本”，不是最高分。边界：平台是作者的产品（PrimeSkills），方法可带走；100 个 case 仍是一个场景，换场景要重做。 上手成本15 分钟（读完）；复跑一轮 1 小时 入口https://juejin.cn/post/7700327310138884106 读详情（翻译 + 要点）→
06 60 元遥控器：给编码 Agent 配一个语音手柄 60 元遥控器当编码 Agent 的语音手柄。 中文 15 分钟 cn:sspai ›
是什么少数派 9 月的文章（作者 neyham），10-25 重新出现在候选里。核心是一个 50–60 元的小米电视蓝牙语音遥控器 2 Pro（RC003）+ 开源 SayAll（HD838A/remote-mic-app）：SayAll 把遥控器的语音键事件接成虚拟麦克风（macOS 的 MiRemoteV 2ch），再配微信输入法的“按住说话”，就能按住语音键口述 Prompt、松手上屏；方向键映射成 Ctrl+Alt+方向键，在 Herdr 里切 Tab / Workspace，OK 发 Enter 确认，返回键发 Ctrl+C/Esc 中断。 为什么值得你花时间你用终端跑 Claude Code / Codex 时，最大的动作量不是写代码，而是在几个 Agent 之间切、确认、中断；这套 60 元的硬件把这三件事变成单手盲操，语音键还能把长 Prompt 说出来而不是敲出来。配置是 15 分钟级：蓝牙配对、装 SayAll、微信输入法选虚拟麦克风，Herdr 的 `~/.config/herdr/config.toml` 里加两套键位，`herdr server reload-config` 热加载；Windows 也有 SayAll 预览版 / 社区适配。边界：要花 50–60 元买遥控器；macOS 新手引导可能卡住，要用两条 defaults 命令跳过；微信输入法 Mac 版对独立 Fn 键不稳，建议用 Control+Option+V 这类组合键。 上手成本15 分钟（配置；需 60 元遥控器） 入口https://sspai.com/post/114741 读详情（翻译 + 要点）→
