GLM-5.3-Flash

靠后训练堆出来的开源编码旗舰，约 750B 参数。
模型 1 小时 hf-org:zai-org

摘要 · 译自原文

Z.ai 的 GLM-5.3 系列（Hugging Face 上已放出 GLM-5.3-Flash 等权重）。官方博客的定调非常直白：「Scaling post-training is all we did for GLM-5.3」——基座与 GLM-5.2 完全相同，提升全部来自后训练：更多环境、更多样的任务、更多花在 RL 上的算力。约 750B 参数（约为 Kimi K3 的三分之一）却在多项 agentic coding 基准上超过 Kimi K3，部分项超过 Claude Fable 5 或 GPT-5.6-Sol；在 Artificial Analysis 的口径里，GLM-5.3-Flash 的智能指数略高于 DeepSeek V4.1-Flash。

Interconnects 认为这不是蒸馏故事，而是三件事叠加：后训练工程能力、比美国实验室快得多的发布节奏（以天计而非以月计），以及逐渐成熟的中国 RL 数据产业。文章也给了两条选型提醒：GLM 旗舰系列一直是纯文本、没有视觉能力，纯文本让它在榜单上更占便宜；Z.ai 对公开 benchmark 的在意程度高于 OpenAI / Anthropic，虽然作者判断还没到「把模型跑废」的程度。安全侧 Z.ai 采用分阶段发布：先让安全合作方在受控环境评估，再开放 API 与权重。

要点

  • 基座与 GLM-5.2 相同，提升全部来自后训练（官方原话「Scaling post-training is all we did」）
  • 规模约 750B 参数，约为 Kimi K3 的三分之一
  • 多项 agentic coding 基准超过 Kimi K3，部分项超过 Claude Fable 5 / GPT-5.6-Sol
  • 纯文本模型、无视觉能力；首发仅 coding plan，权重随后上 Hugging Face
  • huggingface.co 原文不可达，以上据 Interconnects 对 GLM-5.3 的分析与候选池里的 HF 条目

为什么值得你花时间

给平台选 coding / agent 用的开源模型时，这条和上面那条 DeepSeek 正好是一对——一个卖推理成本，一个卖「后训练把中等规模做到前沿」，两条加起来基本能定你下半年自建还是调 API 的天平。注意它是纯文本、没有视觉能力，权重可私有化部署。
