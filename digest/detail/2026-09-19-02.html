genmedia-labs/video-edit

按意图挑换装、换背景还是动作迁移，改现成视频。
技能 15 分钟（RunComfy 账号 / key） skills:trending

摘要 · 译自原文

这是 skills.sh 上的视频编辑技能，出自 genmedia-labs/skills（页面显示累计 553.4K 安装、今日趋势榜第 11、首次收录 2026-08-12，仓库 12 星；安全审计 Gen Agent Trust Hub Pass、Socket Pass、Snyk Warn）。它明确不绑定单一模型，官方定位是「intent-routed」：技能读取用户到底想干什么，再从 RunComfy 目录里挑对应的视频编辑模型——目前列出的三类意图是整体重绘 / 改风格（Wan 2.7 Edit-Video）、从参考片迁移动作（Kling Motion-Control Pro）、以及尽量保住身份的换装与背景替换（Lucy Edit Restyle）。也就是说，它把「该用哪个模型、怎么调」这层判断收进技能，而不是让使用者把三个模型的文档都读一遍。

安装与鉴权走 skills.sh 的通用路径：`npx skills add agentspace-so/runcomfy-skills --skill video-edit -g`（同一技能在 genmedia-labs/skills 包内也有对应条目），运行需要 RunComfy 的账号或 key——与 09-18 简报里发过的同生态出图技能共用同一套 RunComfy 鉴权。

要点

  • 三类意图路由：整体重绘（Wan 2.7 Edit-Video）、动作迁移（Kling Motion-Control Pro）、换装/换背景（Lucy Edit Restyle）
  • 安装：`npx skills add agentspace-so/runcomfy-skills --skill video-edit -g`
  • 需要 RunComfy 账号 / key（与同生态出图技能共用鉴权）
  • 页面累计 553.4K 安装，今日趋势榜第 11，首次收录 2026-08-12
  • 安全审计：Gen Agent Trust Hub Pass / Socket Pass / Snyk Warn

为什么值得你花时间

内容平台的需求里，「把这条素材改成另一个风格 / 换套衣服 / 换个背景」出现的频率不比从零生成低，而且通常要求保留原片人物与节奏；这条给的是「按意图选模型」而不是再学一套提示词，15 分钟拿一段现成素材对比三种改写效果，就能决定你的画布要不要加一个「视频二创」节点。
