MiniMax-H3

开源全模态生成系统，直出带立体声的 2K 视频。
模型 15 分钟（走在线 API，需 key；本地部署另算） hf-org:MiniMaxAI

摘要 · 译自原文

MiniMax 放出的开源全模态生成系统 H3（HF 上 5.35K likes、105 条社区讨论），定位是「通用全模态生成系统」：统一理解由文本、图像、视频、音频组成的多模态上下文，并生成带原生立体声的视频。规格上，输出时长 4–15 秒、帧率 24 FPS、音频 32kHz 立体声，默认短边 768 像素，2K 需要经 H3-Regenerate-2K 这一步；画幅覆盖 21:9 到 9:16；台词稳定支持 11 种语言（阿拉伯语、中文、英语、法语、德语、意大利语、日语、韩语、葡萄牙语、俄语、西班牙语）。

输入侧有两个主变体：**H3-Base-FL2VA** 走首尾帧模式，支持 0 / 1 / 2 张输入图，分别对应文生视频、首帧或尾帧生视频、首尾帧生视频；**H3-Base-Ref2VA** 走全模态参考模式，图像 ≤9 张、视频 ≤3 段（每段 2–15 秒、合计 ≤15 秒）、音频 ≤3 段（同样每段 2–15 秒），所有类型文件总数上限 12。系统还包含第三个模块 H3-Context-IR：输入越复杂，它越重要——专门把多模态指令理解并改写成模型好懂的 Context Intermediate Representation，官方明确建议把它并入生成管线，或按 Prompting Guidance 自建。

入口比较齐全：在线 API 分全球（platform.minimax.io）与中国（platform.minimaxi.com）两套，另有海螺 AI 应用（hailuoai.video）、GitHub 仓库（MiniMax-AI/MiniMax-H3，含官方提示词 skills）、ModelScope 镜像与 Discord。许可证不是标准开源协议，而是自订的 minimax-h3-community-license-agreement，商用前需要读一遍。

要点

  • 输出 4–15 秒、24 FPS、32kHz 立体声、短边默认 768 像素；2K 需经 H3-Regenerate-2K
  • 两个变体：H3-Base-FL2VA（首 / 尾 / 首尾帧，0–2 张图）、H3-Base-Ref2VA（≤9 图 + 各 ≤3 段音视频，文件总数 ≤12）
  • H3-Context-IR 负责把复杂输入改写成中间表示，官方建议并入生成管线
  • 台词稳定支持 11 种语言；画幅覆盖 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16
  • 入口：在线 API（platform.minimax.io / platform.minimaxi.com）、海螺应用、GitHub 与官方提示词 skills；许可证为 minimax-h3-community-license-agreement

为什么值得你花时间

这是少有把「画面 + 立体声 + 多语言台词」在一次生成里做掉的开源权重，正好卡在你平台最贵的那一环（先出画面再回头配音的返工）；下周就能用官方 API 拿同一批 prompt 和 Seedance / Vidu 对跑，也能评估它能否替掉你现在的配音拼接链路。
