open-dots：把一整条 AIGC 生产线拆成 64 个 Agent 技能

把分镜、出图、出片拆成 64 个可调用的 Agent 技能。
其他 15 分钟（只读两份 SKILL.md 抄结构；真要跑通需要 muapi.ai key，且当前安装通道已失效，实际 1 小时以上） weekly:skills-sitemap-diff

摘要 · 译自原文

`anil-matcha/open-dots` 在 skills.sh 上挂了 **64 个技能、合计 66.0K 安装**，是一条从头到尾的 AIGC 内容流水线被拆成可独立调用动作的样子。名字里最像「你的功能清单」的几条：`muapi-storyboard`（输入一句 premise，**一次并行出 N 张关键帧**，默认 6 张，可指定 style，只出图不出视频）、`muapi-cinema-director`（把「史诗感揭示」这类创作意图翻译成技术镜头指令，再喂给 Veo3 / Kling / Luma，**是 64 个里安装量最高的一条，3.0K**）、`muapi-seedance-2`（Seedance 2.0 的 9 种编排：t2v；i2v 支持 1–9 张参考图；视频续接；首尾帧插值；omni 参考（图像 + 音频 + 角色）；omni 训练出持久角色；角色卡；视频编辑；去水印）、`muapi-one-shot-video`（一句 scene + style + 时长，出一条**不剪切的连续镜头**，可选参考图锚定主体）、`muapi-character-story-video`、`muapi-multi-angle-shots` 与 `muapi-multi-angle-reshoot`（分成两条技能）、`muapi-fashion-try-on`、`muapi-product-video-ad-maker`、`muapi-ugc-video-factory`、`muapi-ai-clipping`、`muapi-youtube-shorts`、`muapi-storyboard-to-cooking-video` 等。

提示词层面有两条能直接改掉现有产线的写法。`muapi-nano-banana` 明确把关键词堆砌判为错误做法（禁用 "8k, masterpiece, trending on artstation" 这类词），要求改用完整句子描述物理与光照关系，公式是 **Subject + Action + Context + Composition + Lighting**（表格另有 Style 一行），并且**画面里的文字要用双引号锁死**（`The sign reads "OPEN 24/7"`）；执行入口是 `bash scripts/generate-nano-art.sh --subject … --action … --context … --style …`。`muapi-cinema-director` 则维护一张意图→镜头映射表：Heroic Reveal→低角度广角 + 摇臂上移 / 环绕 + 轮廓光；Tense→荷兰角 + 手持抖动 + 低调硬阴影；Introspective→特写 + 缓推 + 柔和伦勃朗光；Majestic / Epic→超广角 + 无人机飞越 + 黄金时刻；Melancholic→侧脸中景 + 缓拉 + 蓝调去饱和；另有运镜词表（Dolly / Truck / Crane / Orbit / Pedestal）与光学控制（浅景深、宽银幕耀斑、Rack Focus），公式是 `[Shot Type] + [Subject/Action] + [Environment] + [Lighting] + [Camera Movement] + [Lens Effect]`，模型的偏好也写明（Veo3 适合慢速高质感、Kling 适合复杂人物运动与物理、Luma 适合快节奏动作）。

**两个必须一起读的坏消息**。第一，**安装通道今天是坏的**：skills.sh 标注的仓库 `anil-matcha/open-dots` 的 main 分支上已经**没有 `skills/` 或 `library/` 目录**（根目录只有 assets / client / runtime / server / README 等），原技能仓库 `SamurAIGPT/Generative-Media-Skills` 已 301 改名指向它，旧路径**只有 pin 到 commit `aa6a1c7` 时还能读到**——也就是说 `npx skills add https://github.com/anil-matcha/open-dots --skill muapi-…` 很可能解析不到技能；能确认可用的是 registry 上 pin 到该 commit 的版本。顺带解释了这个混乱的来源：**这个名字对应的仓库本体其实是作者自托管的个人 Agent 工作台**（定位 OpenAI Dots / Meta Muse / Grok Bot 的开源替代，MIT，`DEFAULT_MODEL=gpt-5-mini`，deny-by-default 动作网关 + 审批 + 审计，Composio 连接器，可选 Docker/Playwright 电脑运行时），不是技能仓库。第二，**真正出图出片走的是 muapi.ai**：技能里的 `muapi-platform` 要求先跑 `setup.sh` 配好 `MUAPI_KEY`，`check-result.sh` 轮询 prediction，**按量计费**——它不是「装上就能白跑」的那类技能。以上仓库侧信息是经第三方镜像（`r.jina.ai`）读到的，**不是原站核验**。

要点

  • skills.sh 上该仓库共 **64 个技能、合计 66.0K 安装**；安装量最高的是 `muapi-cinema-director` **3.0K**，其后是 `muapi-seedance-2` 2.8K、`muapi-logo-creator` 2.8K、`muapi-nano-banana` 2.7K
  • 业务对口的功能：**自动分镜（storyboard）、一句话成片（one-shot-video）、角色一致性（character-story-video + omni 训练）、多角度重拍、商品视频广告、UGC 视频工厂、AI 剪辑、竖屏短视频、换装试穿**
  • 提示词公式：`nano-banana` 用 **Subject + Action + Context + Composition + Lighting**，禁用关键词堆砌；`cinema-director` 用 `[Shot Type] + [Subject/Action] + [Environment] + [Lighting] + [Camera Movement] + [Lens Effect]` + 意图映射表
  • **安装通道存疑**：仓库 main 分支已无 `skills/` 目录（原仓库 `SamurAIGPT/Generative-Media-Skills` 301 改名），`npx skills add` 可能解析不到；可用的路径是 pin 到 commit `aa6a1c7`；SKILL.md 的 `version: 0.1.0`，首次提交约 7 个月前、最近更新约 6 天前
  • 出图出片依赖 **muapi.ai**（`MUAPI_KEY`，按量计费）；三条安全审计为 Trust Hub Pass / Socket **Warn** / Snyk Pass；技能安装量首次出现在 **2026-02-26**，**不是今天的新东西**——今天是它新增 9 个技能进入 sitemap 差分

为什么值得你花时间

**这 64 个技能的名字，基本就是你平台的功能清单**——自动分镜、一句话成片、角色一致性、多角度重拍、商品视频广告、AI 剪辑、竖屏短视频、换装试穿。它对你有两层价值，第二层更值钱：**第一层是清单**，它告诉你 2026 年 10 月别人把「一条 AIGC 生产线」切成了哪些可独立调用的动作、粒度切到多细（storyboard 只出关键帧不出视频；one-shot 只管一个连续镜头；multi-angle-shots 与 multi-angle-reshoot 是两条不同的技能）；**第二层是提示词结构**，`cinema-director` 那张「意图 → 镜头语言 → 模型选择」的映射表，正是把「用户想要什么感觉」翻译成「模型听得懂的参数」的那一层——如果你现在的分镜还靠人写提示词，这张表可以直接抄成你的分镜模板；`nano-banana` 里「不许关键词堆砌、文字用引号锁死」这两条，今天就能改掉你现有的出图提示词。**建议今天只做一件事**：打开 `muapi-storyboard` 与 `muapi-cinema-director` 两页把 SKILL.md 读一遍（约 15 分钟），把它们的输入参数表与意图映射表抄进你自己的分镜 schema；**先别急着装**，等仓库结构稳定或走 pin 版本。
