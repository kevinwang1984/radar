seedance-2-5-reference-to-video

用参考图锁人物、参考片带运镜，直出带声视频。
技能 15 分钟（RunComfy 需账号 / key） skills:trending

摘要 · 译自原文

这是 genmedia-labs 发布在 skills.sh 上的一个 agent 技能，封装的是 Seedance 2.5 的「参考生视频」能力，跑在 RunComfy 的模型目录上。页面把它的差异点写得很直接：**参考条件生成 + 交付分辨率**——人物身份、产品几何与美术方向来自你给的参考图栈，而不是靠提示词描述；输出直接落在 1080p，不需要从草稿放大。运镜由一段短参考片提供，提示词只负责导演动作，成品带同步音频。

官方给的适用场景是角色成片（consistent character finals）、产品参考片与风格锁定的品牌短片。装法一行：`npx skills add genmedia-labs/skills --skill seedance-2-5-reference-to-video -g`，也可以走 `npx skills add https://github.com/genmedia-labs/skills --skill seedance-2-5-reference-to-video`。模型侧还有 480p 草稿档可以先试。

页面显示该技能累计安装 173.8K（趋势榜 note 记的是 24 小时窗口 16.6K、排名第 2），仓库为 genmedia-labs/skills（GitHub 7 星），首次收录于 12 天前。安全审计三项全部通过：Gen Agent Trust Hub Pass、Socket Pass、Snyk Pass——这是同批 genmedia-labs 技能里少见的干净结果（同 owner 的 video-edit 当时 Snyk 是 Warn）。

要点

  • 参考栈决定身份与美术方向，提示词只导演动作；输出直达 1080p（另有 480p 草稿档）
  • 安装：`npx skills add genmedia-labs/skills --skill seedance-2-5-reference-to-video -g`
  • 调用走 RunComfy，需要 RunComfy 账号 / key
  • 趋势榜第 2（24 小时 16.6K 安装）；技能页累计 173.8K 安装，仓库 genmedia-labs/skills
  • 安全审计：Gen Agent Trust Hub / Socket / Snyk 三项全部 Pass

为什么值得你花时间

你要做的是一句话成片和角色一致性，这条把「哪张图管身份、哪段片管运镜」做成了可调用的技能，省掉自己在 Seedance 接口上拼参考栈；15 分钟装上就能拿一张人像加一段运镜片跑通一条 1080p 带声成片，正好和昨天那条 Wan 3.0 Prime 参考生视频放在一起做选型对比。
