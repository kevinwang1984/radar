Gemini 4 Argon 发布：百万 token 输出，价格约为 Astra 一半

谷歌新旗舰模型，单次输出上限提到百万 token。
中文 15 分钟（读两篇复盘 + 记下价格与两个待验项；模型本身暂未对普通开发者开放） cn:qbitai

摘要 · 译自原文

Gemini 4 Argon 是 Google DeepMind 2026-09-30 发布的新一代前沿模型（官方博客 `blog.google/.../gemini-4-argon/`；`blog.google` 与 `deepmind.google` 本轮在我的抓取环境里解析到非公网 IP、**不可达**，因此以下内容据两处可核验的二手来源：量子位 2026-10-01 的中文复盘，以及 Latent.Space 收录的 Artificial Analysis / Vals / Arena 三方评测数据）。发布口径是「为编码、企业知识工作与网络安全防御设计」，官方宣称在 19 项公开基准里拿下 13 项第一。两个最具体的官方数字：**输出上限 100 万 token**（从此前旗舰的 64K 级别大幅提高；Artificial Analysis 是通过新的 Long Decode Continuation 功能——长回答暂停后跨调用续跑——测到 1M 的，而 Vals 记录的 max output 是 262K）；以及**价格 $4/$20 每百万输入/输出 token，优惠期五折 $2/$10、缓存输入再打 95% 折**。

评测侧可以横向摆放的数字：DeepSWE v1.1 长期软件工程任务 **77.9%**（Claude Opus 5.5 74.2%、GPT-6 Astra 74.1%）；CWE-bench v1 网络安全漏洞修复 **68%**（与 Astra 并列第一）；Vals Index **68.90%** 登顶，平均每题 $15.68；CyberBench 概念验证任务 70%、IOI 2024–2026 满分；Text Arena **1525 分第一**，Code Arena WebDev 第八（1679，比 Gemini 3.8 Flash High 提升 21 名）；Artificial Analysis 智能指数 **53**（与 GPT-6 Astra 持平、高于 GPT-6.1 Sol 的 52），AutomationBench-AA **77.5% 第一**，Terminal Bench 4 只有 **57%**（落后 Sonnet 5.5、Opus 5.5 与 Astra）。最值得单独记住的两条口径：**幻觉率降到 15%**（AA-Omniscience；Astra 为 51%），代价是**准确率 50% 对 Astra 的 63%**；以及**省钱来自单价、不是效率**——Argon 平均每题输出约 62K token，Astra 约 27K，优惠价下每题 $1.99 对 $3.26。

官方给的两个内部落地案例：Argon Agent 在谷歌各数据中心自主识别并落地内存优化方案，全面部署后预计释放 **300+ TiB** 内存；围绕视频解码器的 Rust 移植版本反复实验、替换掉 **3.2 万行 SIMD 代码**，最终版本运行速度达到原 Rust 移植版的 **2.7 倍**且输出一致。可用性是今天的硬边界：**Argon 首批只对 Fairwind 计划里经过审核的政府用户与受信网络安全防御方开放**，谷歌表示会在完善护栏后逐步开放给开发者、企业与消费者。量子位另引 Bloomberg 报道称谷歌内部对模型有分歧（有员工认为实际编码表现不如跑分、前端界面设计仍是短板），谷歌回应「说它编程表现不佳并不准确」。

要点

  • 输出上限 **100 万 token**（此前旗舰为 64K 级；Artificial Analysis 靠 Long Decode Continuation 暂停/续跑测得，Vals 记录 max output 262K）——长任务连续输出是这代的主打
  • 价格：标准 **$4/$20 每百万输入/输出 token**，优惠期 **$2/$10**、缓存输入再打 95% 折；优惠期单题成本约 **$1.99**，Astra 为 **$3.26**
  • 关键跑分：DeepSWE v1.1 **77.9%**（Opus 5.5 74.2%、Astra 74.1%）；CWE-bench v1 **68%**（与 Astra 并列第一）；Vals Index **68.90%** 第一；Text Arena **1525** 第一；Code Arena WebDev 第八；Terminal Bench 4 **57%**（落后前三名）
  • 两处口径提醒：**幻觉率 15% vs Astra 51%，但准确率 50% vs 63%**；**便宜来自单价而非效率**（Argon 62K 输出 token/题 vs Astra 27K）
  • 内部案例：数据中心内存优化预计释放 **300+ TiB**；视频解码器 Rust 移植替换 **3.2 万行 SIMD**、速度达原移植版 **2.7 倍**
  • 可用性：首批仅 **Fairwind 计划**（政府与受信网络安全防御方），普通开发者需等待开放；谷歌内部对实际编码表现存在分歧（Bloomberg 报道）

为什么值得你花时间

你做 AIGC 内容平台，模型侧每次换代都要重算两笔账——**长输出的可行边界**与**单次任务的成本**。这条两个数字都变了：百万 token 输出意味着「一次调用交付一支完整分镜/一份长稿/一次大批量改写」第一次不需要靠外部拼接；$2/$10 的优惠价把「长输出」的单价压到 Opus 5.5 与 Astra 之下。今天能落地的动作是**把 Argon 加进你的候选清单并标上两个待验项**：一是「用了 62K 输出 token/任务 vs Astra 的 27K」（Artificial Analysis 口径）说明省钱来自单价而非效率，批量任务要按 token 而不是按次计费；二是 30 个 Vibe Code Bench 应用全对、但 Terminal Bench 4 只有 57%（落后 Sonnet 5.5 / Opus 5.5 / Astra），**前端与终端类任务别只看总分**。还有一条必须记住的边界：**Argon 目前只对 Fairwind 计划里的政府与受信网络安全团队开放**，你要用还得等，所以今天的正确动作是记下参数与价格、调整选型判断，不是改代码。
