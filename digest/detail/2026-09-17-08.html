Gemini 视频理解进入 agentic 模式

让模型自己决定看视频的哪几秒，省 88% token。
模型 15 分钟（Gemini API key） vendor:deepmind

摘要 · 译自原文

Google DeepMind 9 月 1 日发布 agentic video understanding，覆盖 Gemini 3.7 Flash、3.6 Flash 与 3.5 Flash-Lite。它要替换的是「静态」视频处理：过去模型按固定帧率（默认 1 FPS，可通过 API 调整）把整段视频囫囵吞下，长视频面前开发者只能二选一——要么付高额 token 费，要么用会丢细节的降采样技巧。

agentic 模式下，模型带着目标主动决定「看什么、用多快速度看、用哪种模态看」（画面帧、音轨还是转写），通过内部工具按需加载视频的相关片段，把那一段读进来，形成一个 agentic 循环。官方公布的收益是：token 消耗最多降 88%、分析成本最多降 66%、准确率最多提 7%；其中 3.7 Flash 被描述为落在准确率-成本帕累托前沿上。这个收益在长视频（10 分钟教程到 90 分钟讲座、乃至数小时录像）上最明显。

能力清单直指以前做不了的事：**亚秒级片段定位**（抓住 1 FPS 必漏的瞬间状态变化与剪辑边界，可支撑精确的自动剪辑）、多小时视频里的 needle-in-a-haystack 检索、对可疑时间窗临时提高帧率做异常检测、以及对重复动作与物体的精确计数。开启方式只是把 API 配置里的 processing 设为 `"agentic"`，按标准 token 计费、不额外收费，Google AI Studio 与 Gemini Enterprise Agent Platform 都可直接用；官方还表示该能力将进入 Gemini App，并在未来几个月驱动 YouTube 的 Ask YouTube。

要点

  • 静态抽帧（默认 1 FPS）改为模型主动搜索 / 回看 / 按需提高帧率的 agentic 循环
  • 官方收益：token 最多降 88%、成本最多降 66%、准确率最多提 7%；3.7 Flash 位于准确率-成本帕累托前沿
  • 新能力：亚秒级片段定位（可做精确自动剪辑）、多小时视频检索、异常窗口重采样、动作与物体精确计数
  • 开启只需把 API 配置 processing 设为 "agentic"，按标准 token 计费、无额外功能费
  • 覆盖 Gemini 3.7 Flash / 3.6 Flash / 3.5 Flash-Lite，Google AI Studio 与 Agent Platform 可用

为什么值得你花时间

你在做自动分镜、镜头筛选和成片质检，这套能力正好是「先理解素材再剪辑」那一环，而且不是新模型而是现成模型加一个参数：下周一就能把一条长素材丢给它，试切点定位与镜头计数，顺手把长视频理解的成本压下来——这件事 5 分钟就能改，省下的是你整条素材处理链路的 token 账。
