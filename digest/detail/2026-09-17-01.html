seedance-2-5-image-to-video

把一张静图加上运镜提示，变成带声音的短片段。
技能 15 分钟（RunComfy 需账号 / key） skills:trending

摘要 · 译自原文

这是 genmedia-labs 发在 skills.sh 上的技能，把 ByteDance Seedance 2.5 的「单图生视频」封装成 agent 可直接调用的动作，底层跑在 RunComfy 托管的模型 API 上。给一张静图加一句运镜提示，输出 4–30 秒、720p 的动态片段，可选同步的原生音频，输出画幅跟随输入图。页面显示它今天在趋势榜第 8、安装量 16.4K、收录 12 天。

它的定位被官方写得很清楚：这是**单图窄路**——没有画幅比控制、没有多参考输入，只做「把这一帧动起来」。窄就是它的卖点：没有任何东西能和源图抢身份、服装与构图。这和同族那条「参考生视频」正好互补，后者用多张参考图 + 参考片管理身份与运镜，本条则负责最省事的一图出片。

装上只用一行命令，安全审计三项（Gen Agent Trust Hub、Socket、Snyk）都是 Pass。

要点

  • 单图 + 运镜提示 → 4–30 秒 720p，可选同步原生音频，画幅跟随输入图
  • 无画幅比控制、无多参考输入，官方称「窄」正是为保住源图的身份 / 服装 / 构图
  • 趋势榜第 8、16.4K 安装、收录 12 天；安全审计三项 Pass
  • 一行安装：`npx skills add genmedia-labs/skills --skill seedance-2-5-image-to-video -g`
  • 需要 RunComfy 账号 / key

为什么值得你花时间

你手上「单图动起来」和「参考锁一致性」是两种活儿——昨天那条解决后者，这条 15 分钟就能解决前者：拿一张已有素材直接出 720p 带声短片，不用先想参考栈怎么搭。两条并排跑同一张人像，当天就能判断你的分镜链路该用哪一条兜底。
