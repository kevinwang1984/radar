wan-3-0-prime-reference-to-video

把参考图、视频、音频按编号绑进提示词的生视频技能。
技能 需要申请 key（RunComfy；技能本体 1 分钟装好） skills:trending

摘要 · 译自原文

这是 genmedia-labs 发布的一个 Agent Skill，把 Wan-AI 的 Wan 3.0 Prime「参考生视频」端点（RunComfy 上的 `wan3.0-video-prime`）封成一句安装命令。它和普通文生视频的区别在于提示词里的编号引用语法：一次最多挂 10 张图、5 段视频、5 段音频，然后在 prompt 里用 `Image 1`、`Video 1`、`Audio 1` 逐一点名，从而在整段镜头里锁住角色长相、产品外形和场景调性。技能页面把这套机制直接称为「编号引用绑定」，并以此解释为什么它要作为独立端点存在，而不是并进普通文生视频。

安装方式有两条等价路径：页面顶部的 `npx skills add https://github.com/genmedia-labs/skills --skill wan-3-0-prime-reference-to-video`，以及 SKILL.md 里的 `npx skills add genmedia-labs/skills --skill wan-3-0-prime-reference-to-video -g`。技能本体是提示文档，真正消耗算力的是 RunComfy 的托管 API，所以上手前需要先有 RunComfy 的 key。

要点

  • 安装：`npx skills add genmedia-labs/skills --skill wan-3-0-prime-reference-to-video -g`
  • 引用容量：最多 10 张图 + 5 段视频 + 5 段音频，用 `Image N` / `Video N` / `Audio N` 在提示词里点名
  • 底层端点：`wan3.0-video-prime`（Wan-AI Wan 3.0 Prime，RunComfy Model API 托管）
  • 安全审计：Agent Trust Hub / Socket / Snyk 三项 Pass
  • 页面显示 Installs 159.8K、仓库 genmedia-labs/skills（GitHub 7 stars）；候选池快照里该条记为 installs=16.8K rank=2，两处口径不一致

为什么值得你花时间

你要做的是一句话成片和角色一致性，这条直接给了一套可抄的「参考绑定」写法——把「哪张图管什么」写进提示词语法，装上就能在 agent 里串镜头，不用自己封装 RunComfy 的接口。
