Qwen3.8-Flash-Next

开源多模态模型，下一代 Qwen 架构预览。
模型 1 小时（先走 Qwen Cloud API；本地权重需自备推理） hf-org:Qwen

摘要 · 译自原文

这是 Qwen 放出的开放权重模型，官方定位很明确：它是「支撑 Qwen4 的架构实验预览」，围绕现代 LLM 核心组件如何在规模上协作做了一次重新设计。三处核心变更：**混合注意力配 QSA**——把原来的 Gated DeltaNet 与 Gated Attention 组合，改成 Gated DeltaNet 与 Qwen Sparse Attention 配对，QSA 在 micro-block 粒度而非单 token 粒度做选择，官方说这能显著压低长上下文延迟，而 agentic 负载正在成为主流用法；**Gated Residual**——用逐元素的、数据相关的读门，加每分支的标量写门，来调制加宽残差流里的信息，换取更细的表达力同时保住训练稳定性与低推理开销；**N-gram Embedding**——官方把它当成 MoE 之外的另一条参数扩展轴，靠短 n-gram 索引，算力需求更低、也更适合 offload 到内存受限的加速器。

规格：125B 总参 / 6B 激活，另加 51B n-gram embedding 与 4B MTP；48 层；512 专家（10 routed + 1 shared）；Gated DeltaNet 线性注意力头 V 侧 48、QK 侧 16；QSA 预算 512 blocks 或 2048 tokens；原生上下文 262,144，可扩到 1,000,000；带视觉编码器；对话模板里支持 xhigh / medium / low 三档推理强度。训练配方上，Muon 与 AdamW 按权重类别分工，并取消了传统的 batch-size warmup，直接从目标 batch size 起步。

许可证是 qwen-community-1.0；官方提示托管推理走 Qwen Cloud，其中生产版 Qwen3.8-Flash 默认 1M 上下文并内置工具。权重兼容 Transformers、vLLM、SGLang、TokenSpeed 等。

要点

  • 架构预览定位：支撑下一代 Qwen4，官方称这是「如何高效扩展」而非单纯堆参数的一次回答
  • QSA 在 micro-block 粒度做稀疏选择，而非按单 token；长上下文延迟明显下降
  • N-gram Embedding 是不走 MoE 的参数扩展轴，省算力且便于 offload 到内存受限加速器
  • 规格：125B 总参 / 6B 激活 + 51B n-gram + 4B MTP，48 层，512 专家，原生 262,144 上下文可扩至 1,000,000
  • 许可证 qwen-community-1.0；生产版走 Qwen Cloud（默认 1M 上下文 + 内置工具）

为什么值得你花时间

这是「开源模型下一步怎么扩参」的另一条路线——不堆 MoE 而是堆 n-gram embedding，6B 激活配 1M 上下文，直接关系到你下半年自建推理的成本结构；权重已经能下，下周就能用同一批长上下文与视觉任务和 DeepSeek V4.1-Flash 对跑，判断要不要把它写进选型。
