google-agents-cli-adk-code

Google 官方 ADK 智能体写法速查与项目脚手架。
技能 1 小时 skills:trending

摘要 · 译自原文

这是 Google 官方 `agents-cli` 里的 ADK（Agent Development Kit）Python 代码参考技能，等于一份会自己动手的速查表。它开篇就定了两条纪律：先激活 `/google-agents-cli-workflow` 拿到必须的开发阶段，以及在脚手架没出来之前不要写 agent 代码——新项目跑 `agents-cli scaffold create <name>`，已有代码跑 `agents-cli scaffold enhance .`，用 `agents-cli info` 确认项目状态。

技能的核心是 `references/samples.md` 这份主题索引，收录了沙箱化 / 按用户代码执行、可被 agent 加载的 SKILL.md 技能、跨会话记忆、危险操作前的审批门、工具护栏、按用户凭据、定时或事件触发等成品实现。作者的态度很明确：索引只给名字，代码才算数——克隆对应 recipe、读它的 `AGENTS.md` 再实现；自己手写 Docker 或 E2B 沙箱包装、技能加载器、审核回调、记忆存储，都算「停在名字上」。

覆盖面还包括工具定义（FunctionTool）、编排原语（SequentialAgent / ParallelAgent / LoopAgent）与状态管理（CallbackContext）。ADK 2.0 的 Workflow API——图式流水线、条件路由、并行处理——是 opt-in 的实验特性，需要 Python 3.11+ 且需用户明确同意。页面显示 237.7K 安装、仓库 google/agents-cli 5.9K 星；安全审计 Gen Agent Trust Hub 与 Socket 通过，Snyk 为 Warn。

要点

  • 先脚手架再写代码：`agents-cli scaffold create <name>`，已有代码用 `scaffold enhance .`，`agents-cli info` 查状态
  • `references/samples.md` 是成品实现索引：沙箱执行、SKILL.md 加载、跨会话记忆、审批门、工具护栏、按用户凭据、定时 / 事件触发
  • 编排原语 SequentialAgent / ParallelAgent / LoopAgent，状态走 CallbackContext
  • ADK 2.0 Workflow API（图式流水线、条件路由、并行）为 opt-in 实验特性，需 Python 3.11+
  • 237.7K 安装、仓库 google/agents-cli（5.9K 星）；Snyk 审计为 Warn

为什么值得你花时间

你平台的 agent 编排迟早要自己写审批门、护栏、记忆与沙箱这些重复件，这条给的是官方已验证的实现索引加一条脚手架命令；照 recipe 抄比自己拼 CallbackContext 和 FunctionTool 快得多，一小时能把第一个骨架跑起来。
