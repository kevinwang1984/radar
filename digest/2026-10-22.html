02 Meshy Edit：圈选 3D 模型局部，一句话改一处 在 3D 模型上圈一块，用一句话改局部。 中文 15 分钟 cn:qbitai ›
是什么Meshy 10-20 上线的局部编辑：用套索圈出整块部件（选区同时覆盖正 / 侧 / 背面）或用画刷涂可见表面，再用一句「去掉帽子」这类描述，最多附 5 张参考图，约一分钟生成一个新模型，原模型完整保留；支持 Meshy 6 / 7.1 的高精度模型，带贴图的模型会自动切到未贴图版本再编辑。 为什么值得你花时间你做图像 / 视频生成和画布工作流，「局部重绘」的交互迟早要落到 3D 资产上；Meshy Edit 把流程压成「选区 → 一句话 → 一分钟」，而且每次生成新模型、原模型不动，这个交互和你在视频里做局部重绘的取舍几乎一样。它已经向全部注册用户开放，每次编辑 20 积分，手办 / 战棋 / 潮玩用户可以直接改完去打印，游戏角色可以只换一件配饰就产出多个版本——这两类场景就是「一句话成片」在 3D 侧的现成参照。边界：它只支持 Meshy 6 / 7.1 生成的模型，不是通用 3D 编辑器；贴图模型会先退回未贴图版本，材质细节要自己复核。 上手成本15 分钟（注册即可；每次编辑 20 积分） 入口https://www.meshy.ai/ 读详情（翻译 + 要点）→

是什么Cloudflare 在生日周开源的一组决策模型：27B 的 Clef 和 9B 的 Clef-Flash，输入「状态 + 带类型的问题 schema」，一次前向就返回每个候选选项的概率，不生成自由文本，也不用解析输出；支持文本、JSON、图像、视频，64k 上下文，API 兼容 Typesafe 的 Jev System One。 为什么值得你花时间你在 wayfinder 里让 Agent 做「走哪条工具链、要不要请求权限、这条工单该给谁」这类判断时，让大模型写一段解释又贵又难测；Clef 把这类判断压成一次分类，官方基准里 9B Flash 的中位延迟 38.8ms、27B 是 209.3ms，已经能放进 Agent 的关键路径。它已经上 Workers AI，权重也在 HF，1 小时能跑一次；但 HN 上的质疑要一起看：公开基准容易过拟合，真正该测的是「它知不知道自己该放弃」，以及误报代价高的场景下置信度会不会崩。 上手成本1 小时（Workers AI 或 HF 权重） 入口https://blog.cloudflare.com/clef-decision-models/ 读详情（翻译 + 要点）→
04 DeepSeek DeepInfer：开源推理栈的账本与边界 DeepSeek 开源的推理引擎，靠长缓存省成本。 跟人 1 小时 people:latent-space ›
是什么DeepSeek 10-20 开源的推理框架（Apache 2.0，基于 vLLM，致谢 SGLang / TensorRT-LLM），支持分布式推理、推测解码、SWA Bounded Replay、结构化输出，覆盖 NVIDIA 与华为昇腾；配套的 deepseek-recipe 负责 token 编解码和 Chat Completions / Responses / Messages 兼容层。 为什么值得你花时间你迟早要回答「自建推理能不能比 API 便宜」，DeepInfer 把账本摊开了：单集群 155 万亿 token/天、96% 输入缓存命中、平均首 token 400ms、生成 230 token/s（代码 300）、谷价每卡每小时 38 美元、毛利率 80% 上下、81 天回本；持久 KV 缓存放在约 100 PiB 的 3FS SSD 上，Agent 流量保留 3 天、聊天 7 天，SWA Bounded Replay 只用最近 128 token 重建状态，官方称把 prefill 计算几乎减半。边界同样明确：KV 缓存管理和负载均衡没有完全开源，155 万亿里包含大量缓存命中；vLLM 用 GB200 复现到 decode 只差 6%，说明「只有 DeepSeek 能做到」不成立；要复刻这个集群量级，有人估算需要 3000–4000 张 GB200。 上手成本1 小时（读报告 + 跑 demo；真部署半天起） 入口https://github.com/deepseek-ai/DeepInfer 读详情（翻译 + 要点）→
