是什么CreatorHub 是本地运行的内容管理面板（源码公开），覆盖抖音、小红书、海外小红书、快手、视频号、B站、TikTok、Instagram、X、Facebook 十个平台；同一个界面里管账号、按关键词采集、盯创作者更新、下载图片视频、看评论和弹幕，也能提交发布任务看队列。账号登录态、数据库和媒体文件都存在本地，Windows 用安装版，macOS/Linux 从源码跑（要 Python 3.10 以上）。 为什么值得你花时间你做内容平台，选题采集、素材下载、多账号发布是每天的手工活；它把这条链收进一个面板，还给了跨平台账号矩阵、错峰群发和本地缓存。今天先只接一个平台（小红书或 B 站），用一条自己拥有或获准保存的内容跑通「关键词采集→下载→看评论」，重点看登录态能不能复用、发布失败时给不给原因。边界：仓库没有写许可证，商用或二次分发前要问作者；多账号防关联、搬运和自动发布很容易踩平台规则，别用主账号，只处理自有或授权内容；电脑休眠或服务关掉，任务就停。 上手成本15 分钟（装 Windows 版 + 跑通一个平台） 入口https://github.com/3441293738/creatorhub 读详情（翻译 + 要点）→

03 GLM-5.4：不堆参数，把 28 层再跑一遍的 750B 旗舰编码模型 智谱用重复计算换深度的旗舰编码模型。 跟人 需要申请 key people:simonwillison ›
是什么智谱 11-23 发布的 GLM-5.4，是智谱第一个把「循环 Transformer」（同一组层在一次前向里跑多遍，用重复计算换深度，不增加参数）做成旗舰的模型：把 GLM-5 基座的 28 层跑两遍，总参约 750B（7500 亿），支持文本、图像、视频输入和 100 万词元（token，模型读写文本的基本单位）上下文。目前只能通过 GLM Coding Plan、ZCode 和 Z.ai Chat 用，通用接口（API）和开放权重都还没上线。 为什么值得你花时间你在选编码模型，这条给了一个「不堆参数、用循环换推理深度」的新路线，且它带视觉、能写代码生成视频/游戏/CAD/3D 场景，和你的 AIGC 业务直接相关。但第三方实测很分裂：KingBench 4（第三方编码基准）总榜第 7；第三方评测把它排成开源模型第 1，可权重还没开。跑完 431 分钟、1128 步、约 104 万词元，而 Gemini 4 Neon 是 109 分钟、244 步、约 7 万词元；它的长处在代码审查和安全审计，不适合当主编码代理。今天别急着迁生产，拿 10–20 个你仓库里的真实任务，显式设成 high 档（控制思考时长的档位）、给足超时，记录通过率、耗时和费用，再决定是否把它当第二评审。边界：官方没发模型卡和完整基准，750B/28 层来自官方与媒体报道；会陷入「马拉松式思考」，最大档可能一直想不出答案；权重未开，自托管现在排不进计划。 上手成本需要申请 key（GLM Coding Plan 的访问凭证） 入口https://z.ai/blog/glm-5.4 读详情（翻译 + 要点）→

是什么Simon Willison 把过去 12 个月大语言模型（LLM，用大量文本训练、能读写和推理的模型）的能力变化归成三次拐点：2025-11 的编码智能体（Claude Opus 4.5、GPT-5.1 Codex 开始「默认结果基本对」）、2026 年中的 Fable 类模型（给目标和工具就能硬解复杂问题）、2026 年 9–10 月的 3D 与游戏（Blender 是开源 3D 建模软件，Three.js 是网页 3D 库；模型能出可信模型，Opus 5.5 甚至能花 12 小时把游戏改得「好玩」）。他用自己一年里的项目做例子，不是榜单。 为什么值得你花时间你做视频/画布，3D 与游戏能力不是噱头：它意味着「用代码生成可交互场景」的门槛在降，分镜、运镜、场景预演可以更大胆地交给模型；同时它也提醒你，模型能力是锯齿状的——同一代模型在 3D 上很强，在别的地方可能仍会翻车。今天花 15 分钟读一遍，把「哪些环节可以换更强的模型、哪些可以给更长的自主执行」列成一张小表，别只看单点 demo。边界：这是个人体验复盘，不是基准；Fable 5.2 算不算第四次拐点，作者自己也没定。 上手成本15 分钟（读复盘） 入口https://simonwillison.net/2026/Nov/24/llm-inflection-points/ 读详情（翻译 + 要点）→
