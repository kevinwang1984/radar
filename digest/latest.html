04 EnvHarness：按 Agent 的短板动态改训练环境 按 Agent 的弱点自动改写训练环境。 中文 1 小时 cn:infoq ›
是什么Google Research 开源 EnvHarness：用标准 `reset()` / `step()` 包住现有环境，只改 Agent 看到的接口，不动底层环境与评估器；三个可组合组件——setup 改初始状态、rule 约束状态转移、link 改观察结果；配套 EnvRigger 会分析 Agent 轨迹、找反复出现的薄弱点、生成针对性改动并验证。 为什么值得你花时间你在 wayfinder 这类 Agent 上做评测 / 训练，固定 benchmark 一旦刷满就不再提供新信号；EnvHarness 把“改环境”变成一层可编程包装，论文在 WebArena、SWE-bench Verified、ALFWorld 上把 Gemini 3.1 Flash-Lite、Qwen3.6 27B、Gemini 3.5 Flash、Claude Sonnet 4.6 都抬了 2.9–3.7 个百分点，且保留原任务和人工校验器。**今天就能做**：挑一个你已经在跑的 SWE-bench 子集，按 setup/rule/link 写一层包装，只改一个失败模式（比如工具调用格式），跑一轮 EnvRigger 看是否复现提升。边界：这是研究框架，不是开箱产品；2.9–3.7 个点是平均提升，不代表你的任务；需要自己实现环境适配与验证器。 上手成本1 小时（包一个现有环境，跑一轮 EnvRigger） 入口https://github.com/google-research/envharness 读详情（翻译 + 要点）→
