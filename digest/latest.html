是什么MiniMax 开源的 H3-Image：33.1B 稠密 DiT，6 步采样、无 CFG，文生图与编辑共用一个 checkpoint，最多吃 16 张参考图；每个画幅都直出约 16MP（1:1 4096×4096，21:9 6272×2688），不需要超分。权重 68.65GB，文本编码器复用 MiniMax-H3（66.7GB），另有 17.9GB 的 PE 提示词扩展器；SGLang / vLLM-Omni / diffusers / ComfyUI 都能部署，官方 API 也开着。 为什么值得你花时间你的图像管线最痛的是大图细节、改图保真和多参考合成；16MP 直出把「先生成再超分」这段去掉，6 步把单张成本压下来，统一 checkpoint 让「文生图 → 改图」不用换模型。**今天就能做**：拿 3 张商品图 + 1 张场景图，用 ComfyUI 的 Edit 模板试多参考合成，记录 6 步下的文字 / 手部 / 材质崩点；走 API 则先比同一 prompt 与现有模型的单张成本和 16MP 可用率。边界：BF16 两份权重合计约 135GB，本地要 H200 级 / 多卡 / 量化；社区许可证不是 Apache，商用要单独申请；官方没有独立第三方评测。 上手成本15 分钟（官方 API）/ 1 小时（ComfyUI 本地） 入口https://huggingface.co/MiniMaxAI/MiniMax-H3-Image 读详情（翻译 + 要点）→
02 aws-emulator：官方本地 AWS 模拟器，不连云测 SDK 官方本地 AWS 模拟器，不连云测 SDK。 跟人 15 分钟 people:simonwillison ›
是什么AWS 官方开源的本地 API 模拟器：在本机 / 开发服务器 / CI 起一个 AWS 端点，把 CLI 或 SDK 指过去就能跑，不需要 AWS 账号；支持 server 模式（Linux 包或 Docker）和 Rust 测试的 embedded 模式（每个测试一个隔离实例）。它还带一个 agent skill，`aws agent-toolkit add-skill --skill-name aws-emulator --region us-east-1` 就能让编码 Agent 帮你把环境搭起来（需要 AWS CLI 2.35.0+）。 为什么值得你花时间后端只要碰 S3 / SQS / DynamoDB 这类服务，集成测试就会变成「跑一次真云、等几分钟、还可能脏数据」；本地模拟器把这段变成毫秒级、可重复的测试，CI 里也不用心疼额度。**今天就能做**：在 wayfinder 里挑一个用 AWS SDK 的测试，起 Docker 版模拟器，改 endpoint 环境变量跑一遍，重点看它 release 页的 fidelity 分数和你用到的 API 是否覆盖。边界：官方明说不能用于生产或安全测试；Windows / macOS 走 Docker，Linux 才能装包；各服务覆盖度不一，先查 `issues/things-that-do-not-work/`；默认开 telemetry，记得关。 上手成本15 分钟（Docker 起服务 + 改 endpoint） 入口https://github.com/aws/aws-emulator 读详情（翻译 + 要点）→

是什么Google 11-11 发布的 Decisions API（gemini-decision-1）：把一段共享输入（文本 / 图 / 音频 / 视频 / PDF，最多 256K token）和最多 1,000 个判断问题一起送进去，单次前向返回概率与置信度；支持是/否、2–255 选一、有序 rubric 评分三种题型，端到端 150–250ms，输入 $0.10/百万 token，输出不计费。 为什么值得你花时间你的管线里到处是「该不该 / 选哪个 / 打几分」的小判断——内容审核、模型路由、工具选择、分镜可用性打分；OpenAI 版 Decisions 已在 10-23 评过，这条的增量是原生多模态和单请求 1,000 问题，等于把视频审核也压进同一套调用。官方说它在共享基准上比 Gemini 3.5 Flash-Lite 的 Interactions 调用便宜近 5 倍，Google Notebook 已用它做实时路由、延迟降 40%。**今天就能做**：挑 20 条真实视频 / 图片，写 5 个是/否 + 1 个三选一，和现在的 prompt + JSON 方案比准确率、延迟、单次成本。边界：只做闭集判断，不能生成；置信度校准是官方口径，关键阈值要自己标；256K 是上限，延迟数据对应 16K 以内；文本分类沿用 10-23 的 OpenAI 方案也够。 上手成本15 分钟（AI Studio 免费层） 入口https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/ 读详情（翻译 + 要点）→
