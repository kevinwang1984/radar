是什么Apache 2.0 的 Firebase Local Emulator Suite 替代品：保留 `firebase.json`、SDK、端口和导入导出格式，只把启动命令从 `firebase emulators:start` 换成 `firenook emulators:start`；官方在 21 万文档 / 6.7GB Storage 的真实应用上测到写入中位数 5.1ms vs 208.2ms、峰值内存 2.11GiB vs 22.57GiB、带数据重启 0.59s vs 30.8s。 为什么值得你花时间你跑 wayfinder / Web 端，如果本地用 Firebase，模拟器的 Java + 冷启动 + 每次 export/import 会拖慢每一轮测试；Firenook 是「改一个词」的替换，官方 demo 里 `emulators:exec` 1.39 秒跑完一条测试，还带一个 54 个工具的 MCP，让 coding agent 直接查函数调用、规则拒绝原因和数据——这比让 agent 读日志快得多。**今天就能做**：在现有项目 `npm install -D firenook`，先 `npx firenook init --adopt --dry-run` 看它怎么读配置，再跑一条 `emulators:exec` 测试，对比官方模拟器的启动时间和内存。边界：0.2.x 首个公开版本；Realtime Database / Hosting / App Hosting / Data Connect 不支持；只适合本地和 CI，部署仍要 firebase-tools；不是 Google 官方项目。 上手成本15 分钟（换启动命令，跑一条测试） 入口https://firenook.dev/ 读详情（翻译 + 要点）→
