02 OctaFuse Gateway 2.15.0：把多个 MCP 服务收成一个入口，按调用计费 自建 AI 网关，把多个 MCP 服务聚合成一个入口并逐次计费。 中文 1 小时 cn:juejin ›

03 APUS Reflex Agent 开源：把「决策」和「执行」拆成两个模型 开源的个人 Agent，小模型做决策、大模型干活、记忆独立存。 中文 半天 cn:qbitai ›
是什么量子位 10-14 转的厂商稿（APUS AI 10-13 宣布开源 Personal Agent 产品 Reflex Agent），项目 `APUS-AI-Lab/APUS-Reflex-Agent`，**MIT 协议**，有桌面端 / Web / SDK。**`github.com` 直连不可达，我经 `r.jina.ai` 读到了 README 全文**，里面有一句必须放在最前面：**它基于 DeepSeek Harness 与 DataElement 的 DSH Desktop 构建**（连 Cordis 一起写进了 License 与 attribution 段）。架构主张是 **Model as Harness**：**「大模型」是你自己配的通用模型**（推理、规划、生成内容、提议工具调用），**「小模型」是可选的 Reflex / Jev 决策服务**（在给定的候选与约束里回答结构化的「选哪个 / 打分 / 判断命题」），而 **Harness 本身不是模型**，只负责执行、权限与可持久化的 Session 历史。工作循环叫 **Loop Working**：建立目标 → 选下一步动作 → 由 Harness 执行工具 / 技能 / 子 Agent → **检查证据**（记录工具结果与「决策回执」，而不是把模型说「完成了」当独立证明）→ 恢复相关上下文并继续。记忆层 **Continuum** 把「任务历史」与「单次推理的上下文」分开：记录引用 Session 事件、修正产生后继记录、停用只影响召回不影响历史，**准入默认显式**、有作用域过滤，跨轮与跨进程重启从**同一个 Session** 恢复（**不是**一个全局个人记忆库），每次请求只把有界的候选集与摘录取回。**这条最值得读的是 README 对厂商稿的自我收紧**：量子位那条写「**响应速度最快可达 Claude Code / Codex 的 3 倍**」「**实现真正无限上下文**」，而仓库原文明确写「『无限上下文』与『无限记忆』是**产品方向的名字**——**存储与上下文仍然是有限的**，词法检索会漏掉相关事实，摘要与摘录会丢信息」，还逐条列出「内存里 append 成功不等于磁盘写成功」「**合并进主干不是发布证书**」「目标状态随 Session 恢复，但**自动续跑需要显式 resume**」「安装合格不等于真实模型的完成质量」。 为什么值得你花时间① **它建在你正在用的 harness 上**，所以读它的架构文档几乎等于读一份「别人怎么把 dsh 拆成层」的对照答案：大模型管生成、**小模型只在有界候选集里做结构化选择**、Harness 管执行与权限、记忆独立持久化——这四层的边界正好是你自己那套 AGENTS.md + skills + 记忆机制天天在混的地方。② 三条可以直接抄进自己系统的口径：**「模型说完成」不算证据，要落到工具结果与决策回执**；**自动续跑必须显式 resume**（它把「目标状态随 Session 恢复」与「自动续跑」拆成两件事，与你这段时间一直在用的 goal 恢复语义是同一个坑）；**权限、取消、进程生命周期归 Harness，模型决策不额外授予权限**。③ 那条落差本身就是今天的一课：**对外厂商稿说「快 3 倍、无限上下文」，仓库 README 自己把「无限」收回成方向名**——评估任何新 Agent，先把 README 的 limits 段读完再信标题。④ 边界：**这是开发者预览**，README 自述 macOS 预览用 ad-hoc 签名未公证、仓库当前对 Release 下载要求权限、「快 3 倍」是厂商实测且未给测试细节；我**只读了 README 与它引用的架构说明**，代码本体、release 页与测试都没打开。 上手成本半天（Node 24 + pnpm，`pnpm run setup` 后起桌面端；只想看架构，读 README 与两份架构文档 15 分钟） 入口https://github.com/APUS-AI-Lab/APUS-Reflex-Agent （中文报道 https://www.qbitai.com/2026/10/503165.html ） 读详情（翻译 + 要点）→
