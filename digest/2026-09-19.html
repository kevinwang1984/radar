01 Cactus Needle 3 一个 8–29MB 的模型，让设备离线做工具调用与信息抽取。 小而美 15 分钟 hn:show ›
是什么Cactus 放出的端侧自动化基础模型，整个模型是一个 8–29MB 的二进制（CQ2 量化），29–121M 参数的 Laddered Simple Attention Networks（LSA），把前馈网络整层删掉、只留带门控的注意力。它只练三件事：工具调用（按你给的工具清单挑函数并填参数）、结构化抽取（给一个 schema 把乱文本变成类型化字段）、句子嵌入（本地语义搜索与路由）。最有意思的设计是「智能阶梯」：同一套权重可以按 `needle build --layers n` 切出 2 到 20 层的子网络，每一层都是一个可用模型，参数量 25M（2L）/29M（4L）/52M（8L）/98M（16L）/121M（20L）；树莓派 5 上解码从顶层约 400 tokens/s 到 2 层约 4,000 tokens/s，prefill 1,000→10,000。每个响应都带 `confidence` 分数与 `prefill_tps` / `decode_tps` / `peak_ram_mb`，低于置信度下限的调用进 `suppressed_calls` 而不是猜一个。上手：`pip install cactus-needle` 后用 `@needle.tool` 装饰函数即可跑通；也可走 CLI（`./needle --model needle3.cact --tools tools.json --prompt "..."`）、C（`needle_init` / `needle_complete` / `needle_embed`）、浏览器 WASM 或 WASI 组件，每个平台引擎小于 1MB、推理不联网。微调是 LoRA + `needle build --lora ... --layers 4`：在 DroidCall 上每个子网络涨 18–36 分，从 4 层往上、29M 参数起就超过云端调用的 DeepSeek V4 Flash。底座论文《Simple Attention Networks》给了删掉 FFN 的受控测量：同深度差 0.47 nats、同算力差 0.26 nats、**同参数只差 0.006 nats（约 0.27% loss）**，且差距全落在「query」token 上（上下文里没东西可路由的那部分）。 为什么值得你花时间你平台的画布节点未来要跑在手机、车机或边缘盒子上，「一次工具调用 / 一次结构化抽取」正是端侧最需要的两个动作，而它的运行成本是本地内存而不是 API 账单。15 分钟就能在笔记本上把「一句话 → 结构化 JSON」跑通，再决定哪些能力该下沉到端侧、哪些留在云上。 上手成本15 分钟（`pip install cactus-needle`，无需 key） 入口https://cactuscompute.com/needle 读详情（翻译 + 要点）→
