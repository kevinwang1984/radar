01 OXR：1.3B 的开源文档解析模型 把 PDF 图片解析成带坐标 Markdown。 中文 15 分钟 cn:qbitai ›
是什么SoMark 团队开源的 **OXR（Optical Everything Recognition）**，主模型 **1.3B**，在 OmniDocBench、olmOCR-Bench、DocParsingBench 上分别拿到 **97.18 / 87.84 / 87.76**（团队自测）。它覆盖文字、表格、公式、化学式、代码块等 **13 类**文档元素，输出 Markdown / JSON 并保留版面坐标与阅读顺序；表格转 HTML，公式转 LaTeX，化学式转 mhchem / SMILES。架构上先用轻量版面分析定位区域，再由主模型做内容识别和阅读顺序判断；版面分析可插拔，能换自己的模型和类别定义。 为什么值得你花时间你的素材、截图、研报、论文进入画布或 RAG 前，最烦的是表格被拍平、公式变图片、多栏串读；OXR 把这三件事一起输出成可继续处理的结构。**今天就能做**：用免费 API 或在线 Demo 拿一份你最常解析的 PDF，和 PaddleOCR-VL-1.6 / MinerU2.5-Pro 比同一页的表格与公式；要私有化再下 1.3B 权重。文章给的速度口径是同一张 RTX PRO 6000 上 100 页约 **101 秒**，Paddle 约 145 秒、MinerU 约 255 秒。边界：三榜第一是团队自测，量子位这篇是 SoMark 授权稿，先用你的文档复核。 上手成本15 分钟（免费 API / Demo 试一页；本地部署另算） 入口https://github.com/SoMarkAI/OXR 读详情（翻译 + 要点）→

04 异步后台研究：让长任务拥有独立生命期 让长研究在后台跑，前台还能继续提问和改需求。 中文 15 分钟 cn:juejin ›
是什么ETF Agent 团队 10-28 的工程复盘。核心不是「同时跑两个模型请求」，而是让同一段会话里存在**多次独立执行**：长研究沿自己的 Research Run 跑，短问题有自己的执行身份，前端连接只负责展示进度，不拥有「研究是否继续」的决定权。文章把用户输入分成三类——主聊天框的独立短问、研究面板里的追加要求、自然语言指定目标——并规定只有明确交接的调整才进入原研究；目标不明确先澄清。还区分了三个事实：消息已保存、后续请求实际带上、最终报告满足要求，三者不能互相冒充。 为什么值得你花时间你做 Agent 产品，长任务占住对话框是迟早要解决的体验问题；更值钱的是它对「取消」的拆解——用户主动停止研究，和为采纳新要求而中断当前请求，是两件事。文章给了一个真实事故：请求适配层把「局部抢占」压成普通「取消」，运行时误以为整项研究该收尾，最终报告缺了关键比较。这个坑直接对应你 wayfinder 里长任务被误杀的风险。**今天就能做**：用 15 分钟读一遍，把「任务身份、三类输入分流、三层证据、容量满就明确拒绝」写进你的任务模型。边界：这是 ETF Agent 的复盘，不是通用框架，代码未开源；文章自己也承认交互跑通不等于研究结论正确。 上手成本15 分钟（读 + 对照你的任务模型） 入口https://juejin.cn/post/7701566014480531494 读详情（翻译 + 要点）→
05 离线编码 Agent：断网时用本地模型改一行代码 断网时用本地模型和 OpenCode 写代码。 跟人 1 小时 people:latent-space ›
是什么Thomson Reuters 首席工程师 Rittika Jindal 的实测：**OpenCode 1.19.4 + Ollama + Qwen3.5 9B**，全部跑在笔记本上。`opencode.json` 把主模型和小模型都指向本地 Qwen3.5 9B，`baseURL` 指向 `127.0.0.1:11434`，只启用本地 provider，编辑和 shell 命令都要确认，并屏蔽 web 工具。验证用的项目是一个有 bug 的费用计算器：`total =` 每轮覆盖，输出 8.00 而不是 25.50；断网后让 Agent 修，Qwen 提出一行 `total += Decimal(amount)`，请求编辑权限、跑完 5 个测试，全过。 为什么值得你花时间你经常在通勤、断网或不想把代码发到云端时想改一个小东西；这套组合把「读文件、改一行、跑测试」完整留在本地，而且配置里显式禁掉了 web 工具，断网测试是真的断网。**今天就能做**：花 1 小时装 OpenCode + Ollama，拉 `qwen3.5:9b`，先跑文章附带的费用计算器例子，确认断网后还能跑测试。边界：9B 只适合小任务，文章也只验证了一行修复；大仓库、陌生框架别指望；OpenCode 在云模型基准里 token 消耗约为 Goose 的 40 倍，本地慢不慢要自己测；Windows 上命令按 Ollama / OpenCode 文档改。 上手成本1 小时（装 OpenCode + Ollama + 拉 9B 模型） 入口https://github.com/RittikaJ/opencode-qwen-local-setup 读详情（翻译 + 要点）→
